# Template One: Leon Agency Landing Page

A landing page for an agency called Leon, built to practice HTML and CSS layout from a design.

**Live demo:** https://moh9180812-cyber.github.io/Html_And_Css_Template_One/

## Features
- Responsive landing-page sections
- Custom Work Sans font
- normalize.css and Font Awesome for a consistent base and icons

## Built with
HTML, CSS, Font Awesome

## Run locally
```bash
git clone https://github.com/moh9180812-cyber/Html_And_Css_Template_One.git
cd Html_And_Css_Template_One
```
Open `index.html` in your browser. No build step or install needed.
